CÁCH MỞ GAME (QUAN TRỌNG — ĐỌC TRƯỚC KHI MỞ)
------------------------------------------------
KHÔNG mở trực tiếp bằng cách double-click index.html: Chrome chặn fetch() từ file://
nên game sẽ báo "Không tải được dữ liệu game (assets/data2.json)" và dừng lại.
(Không chỉ data2.json: mọi sheet JSON của game cũng tải bằng fetch() nên đều hỏng
khi mở kiểu file://. Đây là giới hạn của trình duyệt, không phải lỗi game.)

- Windows: double-click MO-GAME.bat (tự mở trình duyệt tại http://localhost:8000/).
  Cần Python (nếu có) hoặc PowerShell có sẵn của Windows 10/11.
- Mac/Linux: chạy ./MO-GAME.sh (cần Python 3).
- Cách thủ công (mọi máy): mở terminal/cmd tại thư mục này, chạy:
    python -m http.server 8000
  rồi mở trình duyệt: http://localhost:8000/
- Để TẮT game: đóng cửa sổ server (Ctrl+C trong cửa sổ đó).
